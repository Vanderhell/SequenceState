# Changelog

## [0.1.0]

- Added the portable C11 Trace / C primitive with known-event rollback.
- Added the exact associative Compose / H primitive for ordered block
  composition and tree reduction.
- Added the exact composable Range / H2 primitive for prefix operations and
  fixed-memory sliding windows.
- Added production examples, deterministic golden vectors and property tests.
- Validated the portable core across host compilers and on ESP32-S3 hardware.
