# Survivor golden corpus

Generated by `experiments/survivor_golden.c` for versions C-1.0, E-1.0, H-1.0 and H2-1.0. Cases include empty, zero, maximum, alternating, ascending, descending, repeated, random64, and a structured trace/protocol sequence. GCC Release, MSVC Release, and Clang-cl Release produced byte-identical rows.

The generator is intentionally kept in the repository so the corpus can be regenerated rather than copied into a second implementation.
